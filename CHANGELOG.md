# Changelog

## V5.3

- Shorter, cleaner hideout summary with compact labels and fewer repeated lines.
- Replaced **Burst** in the compact HUD with **UP**, the percentage of map time
  spent in active combat.
- Kept map **Quant**, **Rarity**, and **Pack Size** in the hideout footer.
- Fixed map rarity reading as 0% by using the correct ExileAPI map-stat key.
- Improved observed damage tracking for fast kills, explosions, ignites, and
  Legion-style monster activation.
- Retains the V5.1 fix for map bosses in separate internal boss arenas.
